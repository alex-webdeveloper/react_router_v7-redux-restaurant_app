## Getting Started
launch db: % json-server --watch  app/db.json --port 3004

### Installation
Install the dependencies:
```bash
npm install
```
### Development
Start the development server with HMR:
```bash
npm run dev
```
Your application will be available at `http://localhost:5173/react_router_v7-redux-restaurant_app/`.
## Building for Production
Create a production build:
```bash
npm run build
```
## Deploymen on gh-pages
npm run deploy
